## Priority Implementation Plan

### Phase 1: MONEY PAGES (do first — each one is a new client source)

1. **Create /priser** — "naprapat pris stockholm"
   - Every competitor has one. People searching this are ready to book.
   - Include: price, what's included, friskvårdsbidrag info, insurance info
   - *Requires: confirmed prices from Hanna*

2. **Create /friskvardsbidrag** — "naprapat friskvårdsbidrag"
   - High search volume, directly tied to booking decision
   - *Requires: confirmation that Hanna accepts friskvårdsbidrag*

3. **Create /kakledsbesvar** — "käksmärta naprapat" / "käkledsbehandling"
   - Already listed as a service on the site, no dedicated page
   - Low competition, high booking intent
   - Include exercises section for "käkspänning övningar"

### Phase 2: EXPAND SYMPTOM PAGES (capture more search traffic)

4. **Create /loparkna** — "löparknä behandling stockholm"
5. **Create /halsporre** — "hälsporre behandling stockholm"  
6. **Create /tennisarmbage** — "tennisarmbåge behandling"
7. **Create /skuldersmarta** — "ont mellan skulderbladen" / "skuldersmärta"

Each page follows the existing symptom page template with:
- H1 with symptom + "behandling" + location
- What it is, common causes
- How naprapati helps (cautious, no promises)
- Self-care tips / exercises
- Medical safety note (1177/112)
- Prominent booking CTA
- Structured data (MedicalWebPage + BreadcrumbList)

### Phase 3: AUTHORITY CONTENT (builds trust, captures informational searches)

8. **Create /vad-gor-en-naprapat** — educational, links to all service pages
9. **Create /naprapat-vs-fysioterapeut** — comparison, positions Hanna as expert
10. **Add exercises sections** to existing symptom pages (ryggsmarta, nacksmarta)

### Phase 4: STRENGTHEN EXISTING

11. **Fix /naprapat-odenplan** — reduce 100% bounce rate
    - Add patient journey description
    - Add "Så här hittar du till mig" with embedded map
    - Add stronger above-fold CTA
    - Add internal links to symptom pages

12. **Expand thin pages** — huvudvark, ischias, idrottsskador need more depth
